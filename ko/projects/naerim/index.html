네이티브 커피 기록 앱

내림

다시 내리고 싶은 한 잔의 조건을 기억하다.

추출을 기록하고 레시피를 보관하며, 한 잔마다 달랐던 조건을 비교하는 네이티브 커피 기록 앱입니다. iPhone·iPad용으로 직접 개발·출시했고 한국어·영어·일본어로 현지화했습니다.

시스템 연결 구조

기술 설명은 2026년 9월 17일 확인한 소스 기준입니다. App Store 출시 버전에는 일부 변경이 아직 포함되지 않을 수 있습니다.

  1. 01SwiftUI · 편집용 값 타입 초안
  2. 02세션 조정자 · 저장소 계층
  3. 03SwiftData · JSON 체크포인트

화면에서는 값 타입을 편집합니다. 저장소 계층이 영속화를 담당하고, 공용 조정자가 여러 앱 창에 걸쳐 진행 중이거나 저장하지 않은 추출을 관리합니다.

화면 뒤의 구현 선택

01

카탈로그가 바뀌어도 과거 기록은 그대로

추출 당시의 레시피와 장비 값을 스냅샷으로 기록합니다. 카탈로그 항목을 수정하거나 삭제해도 이전 한 잔의 조건은 바뀌지 않습니다.

02

끝내지 못한 작업 복구

단조 증가 시계로 경과 시간을 추적하고, 원자적으로 저장하는 JSON 체크포인트로 앱 재실행 후 복구를 지원합니다. 결과 저장과 체크포인트 삭제의 상태를 대조해 재시도 시 이미 저장된 추출을 알아볼 수 있도록 합니다.

03

초안을 바꾸기 전에 검증

레시피 물량을 조정할 때 오버플로, 유한하지 않은 값, 반올림 잔차를 확인한 뒤 새 초안을 만듭니다. 조정에 실패하면 원래 초안을 보존합니다. 이 사례는 독립 Swift 패키지로 공개했습니다.

내림

AI를 활용한 방법

범위를 정한 개발 작업에 Codex를 활용했습니다. 추출 입력 개선에서는 필요한 측정 항목을 개별적으로 선택하는 단순한 흐름을 요청했습니다. 구현 과정에서 미입력 값, 목표 물량과 실제 물량, 새 초안과 이전 결과의 구분을 유지했습니다.

제품의 동작을 정의하고, 받아들일 변경을 선택하며, 출시를 결정하는 책임은 제가 맡습니다. 빌드, XCTest 결과, UI 확인, 소스 스냅샷으로 검증 범위를 기록합니다. 추출과 비교 기능에는 네이티브 Swift 데이터·계산 로직을 사용합니다.

코드와 검증

공개 레시피 검증 패키지는 정해진 324개 비율·목표량 조합을 포함한 14개 테스트와 GitHub Actions 실행을 통과했습니다. 전체 앱의 별도 검증 결과는 기술 상세 문서에 날짜와 함께 기록했습니다.
